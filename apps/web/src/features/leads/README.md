# Leads Feature

M6 implements the frontend CRM workspace for real API-backed lead management.

Current views:

- Leads list with search, filters, sort controls and lead selection
- Pipeline board grouped from database-backed pipeline stages
- Lead detail panel with overview, activity timeline, stage change and owner assignment
- Conversation tab with the internal simulator for real conversation/message records

Qualification, meetings and AI insight tabs are reserved for later milestones and do not contain mock runtime data.
